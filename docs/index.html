ACTOR AI Security Framework

AI Controls for Trust, Oversight, and Resilience

ACTOR is an open, tool-neutral security control framework for the full AI estate: agents, models, the data they learn from and read, AI platforms, and how people use AI. It adds the controls AI needs alongside the framework you already run.

Why AI needs its own controls

Current frameworks were built to secure people and conventional systems. AI is neither. An agent acts like a user, but it is not a person. A model runs like software, but its behavior is not deterministic. Both can be manipulated by the content they read, and both change over time.

ACTOR treats AI as its own class of actor. Agents get their own identity, delegated authority, supervision, and offboarding. Controls assume manipulation and misbehavior, and limit what a compromised AI can do.

What makes ACTOR different

  • Agents are security principals. Every agent is identifiable as itself, with delegated authority and a human owner. Agents never sign in with a person's credentials.
  • Humans hold authority, agents hold capability. High-impact actions need a human approval the agent cannot satisfy.
  • Assume manipulation and misbehavior. Controls limit what a manipulated or misbehaving AI can do, not only whether it happens.
  • An overlay, not a new program. Most controls extend practices you already run, such as vendor risk, incident response, and identity management.
  • Works for vendor AI too. Controls say how to meet them when a vendor runs the AI, not only when you build it yourself.
  • Tiered and testable. Foundational, Managed, and Advanced tiers. Every control is written so an auditor can test it.

Where to start

  1. Pick your deployment profile. Consumed (you use vendor AI as delivered), Configured (you also build agents or assistants on vendor platforms), or Built (you also develop or host your own AI).
  2. Start with the 18 ACTOR Essentials. They address the most common AI failures for organizations that mainly use vendor AI.
  3. Work through your tier. Controls marked Extends add AI scope to something you already do. Controls marked New are AI-specific work.

Mapped to the frameworks you already use

Every control maps to NIST CSF 2.0, NIST SP 800-53 Rev 5, the NIST AI RMF 1.0, the OWASP Top 10 for LLM Applications (2025), and the OWASP Top 10 for Agentic Applications (2026). Reuse your existing audits and evidence.

ACTOR also maps to the ten design tenets for agent identity, authentication, and authorization that NIST published in October 2026.
